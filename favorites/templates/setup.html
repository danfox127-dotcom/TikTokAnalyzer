    Optional: fewer taps

    Copy the link, then one press.

    {% if ready['save-copied-link'] %} {{ icon('plus') }}Install Save copied link {% endif %}

    In TikTok or Instagram tap Share → Copy link, then use whichever you like:

    • Double-tap the back of the phone. Settings → Accessibility → Touch → Back Tap → Double Tap → Save copied link.
    • The Action Button (iPhone 15 Pro and later). Settings → Action Button → swipe to Shortcut → choose Save copied link.
    • Control Center. Swipe down from the top right, tap +, then Add a Control, search for Shortcut, and choose Save copied link.
    • Inside Faves. The Save copied link button on Home. No shortcut needed.
  5. ✨

    Optional: save when you leave the app

    Copy the link; Faves keeps it as you close TikTok.

    {% if ready['auto-save-copied-link'] %} {{ icon('plus') }}Install Auto-save copied link {% endif %}
    1. Install Auto-save copied link and tap Add Shortcut.
    2. In the Shortcuts app, tap Automation at the bottom, then + (or New Automation).
    3. Choose App. Tap Choose, pick TikTok, Instagram and YouTube, then Done.
    4. Untick Is Opened and tick Is Closed. Choose Run Immediately and turn off Notify When Run. Tap Next.
    5. Pick Auto-save copied link. That's it.

    From then on, a link you copy in one of those apps is kept when you leave it. Links you've kept already are skipped, and only TikTok, Instagram and YouTube links are ever kept. If your iPhone asks whether the shortcut may paste, choose Always Allow. Menu names vary a little between iOS versions.
